# results

Artifacts generated by the scripts in `src/`.

| Folder | Content |
|---|---|
| `comparison/` | Comparison of the three models on the same test set: `metrics_comparison.(csv\|md\|png)`, `roc_curves.png`, `confusion_matrices.png`. |
| `decision_tree/`, `random_forest/`, `xgboost/` | `metrics.json` (metrics + hyperparameters + library versions), `feature_importance.(csv\|png)`, `confusion_matrix.png` and model-specific plots (tree drawing). |
| `<model>/original/` | Plots produced by the **original** scripts, kept untouched for reference. |

**Which data produced these results?** The files in `comparison/` and in each model folder (outside `original/`) were
generated with the **full 100k-order dataset** (`data/raw/`, not versioned), with `python src/compare_models.py`.
Running the same command on a fresh clone uses `data/sample/` and produces different (noisier) numbers.

**About `original/`:** the Decision Tree and Random Forest plots there were produced on the small `vendas` dataset, with
a different preprocessing, so they are **not comparable** with the new results. The XGBoost importance plot was produced
on the `pedidos` dataset but with the original preprocessing. They are kept to document the evolution of the project.

`predictions_new.csv` (scores for the new orders) is written by every run but ignored by Git because of its size.
